## Uso del backlog

1. Tomar primero las decisiones y dependencias del M0.
2. Mantener un issue por resultado verificable; usar el criterio de aceptación para cerrar cada tarea.
3. Registrar decisiones y evidencia en el issue correspondiente.
4. Revisar bloqueos antes de iniciar una tarea dependiente.
5. Para el piloto, registrar cifras de conversión, fallos, tiempo y costo por pedido.
